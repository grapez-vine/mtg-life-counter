# mtg-life-counter
Basic mtg commander life counter made with python. Uses curses UI in terminal. It allows 2 to 4 players with custom deck names and colors. It has buttons for damage and separate commander damage. It also allows custom amounts of damage to be able to go into negatives. When a player reaches -25 health, the "Overkill" screen is shown to award doing excess damage. I plan to add more achievements similar to MTG-Forge and keep game logs. I also want to try and add a simple rules section and make it run on Raspberry Pi displays.

# Requires "pip install art" to add ascii art library.

This was tested in Ubuntu on 1080p monitor.
